<h1 align="center">Elyrith</h1>
<h3 align="center">Your desktop. Reimagined.</h3>

Elyrith is a modern, Wayland-native desktop environment for Linux, built around a different approach to window management.

At its core is a tabbed interface that brings related windows together, making it easier to organize applications and move between tasks without cluttering your workspace.

We're building Elyrith as a complete desktop environment, with a focus on thoughtful design, smooth interactions, customization, and performance. The goal is to create something that feels familiar where it should, but isn't afraid to rethink how a desktop works.

Elyrith is open source and currently under active development.
